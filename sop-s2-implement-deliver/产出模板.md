# S2 产出模板

所有形态有 `S2/`：`S2-01`、`S2-02-sql/`、`S2-03-config/`、`S2-04-verify/`、`S2-06`、`S2-07`。在线=分支/PR；离线或不可编译另有改动包。

## 改动包目录（离线 / 不可编译）

```
handoff/
  {需求}-r{N}/                 当前终包（用户只看这个；白名单如下）
    README.md / manifest.txt / precheck-report.txt
    patches/{目录}.patch           相对基线全量（必有）
    {目录}-r{N-1}to-r{N}.patch     可选；仅相邻；无 diff 或本轮 A 类则不生成
  _archived/{需求}/r{K}/           更早终包（出 r{N} 时移入）
```

**白名单**：禁嵌套 `S2/`、远距增量、其它根文件；与 `artifacts/.../S2/` 并列。出下一轮前归档。「你要做的」只指当前终包。出包前全量 `--check`（有增量先落到上轮终态）。

### README.md

**内容预算**（H6）：≤80 行；「你要做的」≤35/前置≤2/本轮≤6/步≤120 字；禁嵌套、上轮报错、待定 Q；差异≤5；增量/全量命令分块。

```
需求：{编号} {短名}      改动包：r{N}      生成日期：
快照日期 / 基线：{目录} {commit} …
本轮范围：验证清单 第 {x} 节
与上一轮差异（r1 不写）：- B-01 …（≤5 条）
基线自证：全量 --check PASS；相邻增量链 = HEAD {commit}（无增量写「本轮仅全量」）

## 用户本轮要做（与 00-当前位置同文）
你要做的（目录：handoff/{需求}-r{N}/）
先选一行：
| 你当前已应用到 | {仓A} | 编译→重启 |
| 从未打过 / 仅基线 | 本包 patches/ 全量 | {模块序}→{服务} |
| 正好已到 r{N-1}（未手工改） | {仓}-r{N-1}to-r{N}.patch / 无需再打 | {仅改}→{服务} |
| 其他（含已到 rN） | 已到 rN：不用再打；否则丢弃→基线→全量 | 同「从未」 |
前置（一次性；无则删；≤2 步）：
1. 打上表所选 → 按该行编译重启 — 粘回：apply/编译/重启
2. 配置：`S2-03-config/{完整文件名}`（用途≤12字）— 粘回：已配/否
本轮操作（≤6 步；禁嵌套；禁贴上轮报错）：
1. SQL：`S2-02-sql/{完整文件名}`（用途）检查后执行 — 粘回：…
2. 核对：上线手册§七 {项} — 粘回：是/否
3. 前端：部署→重登→复验 {菜单} — 粘回：可达/404
4. 冒烟：S2-07 §x {M 条目} — 粘回：每条通过/失败
仍待你回报：无 / …

## 门禁
| 门禁 | 结果 | 依据 |
| 编译 | 无法证明（本机不能编译，请在下方执行） | |
| 单测 | 通过 n 条 / 无法证明（原因） | |
| precheck | PASS | precheck-report.txt |
| 审查 | 需求不符 0 / 交付与部署 0；后续优化 n 条 | S2/S2-08-审查.md |
| 交付可用性 | 通过 | 找茬 1–9 无否 |
| 验证清单 | 本轮范围 | |

## 在真实仓里执行（分组复制；两组禁止粘进同一次执行）
见下方两组独立命令块；按选表只复制对应一组。
apply 失败：原样带回（A 类）；软回退全量，仍败再快照刷新。
precheck WARN 说明：
```

**【仅当：正好已到 r{N-1}】** 只复制本组（禁再跑全量）：

```
cd {真实仓根}
git apply --3way --check --directory={子路径} {仓}-r{N-1}to-r{N}.patch && git apply --3way --directory={子路径} {仓}-r{N-1}to-r{N}.patch
git add {子路径} && git commit -m "{需求编号}: r{N} 增量"
```

按选表编译→重启，粘回。

**【仅当：从未打过 / 软回退】** 只复制本组（禁先打增量）：

```
cd {真实仓根}; git checkout {开发分支或生产 tag}; git pull; git checkout -b feature/{需求编号}
git apply --3way --check patches/{目录}.patch && git apply --3way patches/{目录}.patch
git add -A && git commit -m "{需求编号}: r{N}"
```

多仓逐目录重复；编译：{命令}；按「用户本轮要做」执行后粘回；通过后 push/PR。

## S2-02-sql/*.sql（文件头）

只写当前约束；禁事故编年。`适用：最终态|升级清理`（升级清理不进手册首次步骤）。

```sql
-- 需求：{编号}   库：{库名}   执行顺序：{n}   适用：最终态|升级清理
-- 可重复执行：是
-- 执行前检查：SELECT COUNT(*) ... TABLE_NAME='tb_xxx';
-- 回滚：DROP TABLE IF EXISTS tb_xxx;
CREATE TABLE IF NOT EXISTS tb_xxx ( ... );
INSERT INTO tb_dict (id, type, code, name)
SELECT {固定id}, '{类型}', '{编码}', '{名称}' FROM DUAL
WHERE NOT EXISTS (SELECT 1 FROM tb_dict WHERE type='{类型}' AND code='{编码}');
```

`reset_test.sql`（可选）：测环境复位，不进上线手册。

## S2-03-config/*.diff

```
# 适用：最终态 | 升级清理
# 配置文件：{dataId 或文件名}   位置：{锚点}
# 执行前检查：搜索 {键}，已存在则跳过（删除类：不存在则跳过）
# 回滚：自包含；禁「按旧 handoff 已删文件」
+   - /{前缀}/{新路径}/**
```

**最终态**=新环境目标（首次必做）。**升级清理**=仅迁移/删错配，只进「三附」。
