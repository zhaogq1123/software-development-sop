# R 复盘

## 触发

按上线手册上线完成且观察期结束。未上线不做 R。

## 步骤

1. 收上线事实：日期、与手册偏差、验证与观察期、是否回滚 → `R-01`。
2. 从 `S3-02` 与 S1 走读列「实现/验收才发现、S1 没查到」：他需求会用→回填手册（机制/参照/登记/不可用接口/环境）+「回填记录」；占用标「已上线」。仅本需求→不回填。
3. 记三个指标（生命周期 › 指标）。B 类与归因为设计错的 C：能否被走读/取样/precheck 提前拦？能则改模板说明或加 precheck。
4. AC 线上被推翻→改 S1 模板 AC 写法说明。
5. 「无法证明」项上线后出问题→写清代价，问用户是否补能力（测试依赖/可编译环境/verify 鉴权）。
6. `S2-08`「后续优化」列给用户排期；未排期保留在复盘。

## 规则

- 只改手册、模板说明、precheck。不改阶段划分。
- 改 skill 按 SOP约束，改完 `--lint-sop`。
- 回填带出处。

## 产出

`R-01-复盘.md`；手册回填；可能的模板/precheck 改动。

## 出口

「回填记录」有本需求一行（可为「无回填」）。有后续优化→「你要做的」用「R 有后续优化」，否则「无」；对话末条同文。
