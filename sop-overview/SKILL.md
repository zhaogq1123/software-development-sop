# sop-overview

本目录是 sop-v2 总纲：

- [生命周期.md](生命周期.md)：阶段出口、自我纠错、门禁、问题分类、类型裁剪、验收走查、交付可用性、当前位置、决策（含数据源必问）、单一真相源等。
- [环境准备.md](环境准备.md)：本机编译加速、离线快照刷新、用户侧软回退。
- [SOP约束.md](SOP约束.md)：改 sop-v2 的硬约束与 lint。

## 该用哪个 skill

| 时机 | skill |
|------|-------|
| 建/回填手册 | `sop-s0-project-handbook` |
| 需求/缺陷/配置变更 | `sop-s1-requirement-design` |
| 改动面确认后写码出包 | `sop-s2-implement-deliver` |
| 编译/用例/部署结果 | `sop-s3-verify-fix` |
| 上线完成 | `sop-r-retrospective` |

## 开工前先读

1. `artifacts/{需求}/00-当前位置.md`（有则继续；无则 S1；无手册先 S0）。
2. `artifacts/_project/S0-01-项目手册.md`。
3. `生命周期.md`：自我纠错、门禁、问题分类、类型裁剪、当前位置、决策。

每阶段、S3 每轮、更新 SOP 后都开新会话；只靠 `00-当前位置` 与 `artifacts/` 接续。对话末条只发「你要做的」正文（生命周期 › 当前位置）。

## 三条总规则

1. skill 只写通用流程；项目/需求专有进手册、`precheck.json` 或需求产物。
2. 一事实一处；别处引 `D`/`REQ`/`AC`/`Q`。
3. 门禁三态如实；自评与自测不算证据。出口前反复检查见自我纠错。
